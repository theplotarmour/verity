# 10 Supervisor

## Role Purpose

This role is responsible for department execution oversight and exception handling.

## Experience Framework

- morning priorities
- active-shift operating loop
- afternoon correction and exception handling
- end-of-day closure
- KPIs
- notifications
- common actions
- desktop vs mobile expectations
- permissions and data boundaries

## Design Rule

The 10 Supervisor experience should expose only the operational depth needed by this role, while keeping workflow speed and signal clarity high.
