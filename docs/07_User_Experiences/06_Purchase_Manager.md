# 06 Purchase Manager

## Role Purpose

This role is responsible for replenishment readiness, vendor coordination, and inbound visibility.

## Experience Framework

- morning priorities
- active-shift operating loop
- afternoon correction and exception handling
- end-of-day closure
- KPIs
- notifications
- common actions
- desktop vs mobile expectations
- permissions and data boundaries

## Design Rule

The 06 Purchase Manager experience should expose only the operational depth needed by this role, while keeping workflow speed and signal clarity high.
