# 12 Worker

## Role Purpose

This role is responsible for single-job execution with clear instructions and issue reporting.

## Experience Framework

- morning priorities
- active-shift operating loop
- afternoon correction and exception handling
- end-of-day closure
- KPIs
- notifications
- common actions
- desktop vs mobile expectations
- permissions and data boundaries

## Design Rule

The 12 Worker experience should expose only the operational depth needed by this role, while keeping workflow speed and signal clarity high.
