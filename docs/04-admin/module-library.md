# Module Library

The Module Library is the admin-facing view of the Module Catalog.

## Required Columns

- module name,
- status,
- version,
- category,
- active client count,
- dependencies,
- price/tier,
- owner/developer,
- origin,
- reuse policy,
- last updated,
- known limitations.

## Required Actions

- preview module,
- preview dependencies,
- preview permissions,
- preview navigation/dashboard contributions,
- activate for tenant,
- deactivate for tenant,
- inspect affected clients,
- create custom module request,
- mark lifecycle status.

## Rule

An admin should not need a developer to enable an existing active module for a tenant.
