---

### Bucket

Source: MinIO Buckets Reference
Definition: A unique logical folder-like container used to organize S3 objects.
Key attributes: `name` (String, globally unique), `versioning_status` (Enabled | Suspended), `lifecycle_rules` (List).
Notes for Verity: Verity can organize files into buckets by tenant ID or by entity category (e.g. `work-order-photos`, `signed-contracts`).

---

### Object

Source: MinIO Objects Reference
Definition: The binary file data stored within a Bucket, along with associated metadata.
Key attributes:
- `key` (String) — the unique path/name of the object inside the bucket
- `size` (Long) — file size in bytes
- `content_type` (String) — MIME type
- `metadata` (Custom key-value map)
- `version_id` (String) — unique identifier if versioning is active

---

### Presigned URL

Source: MinIO Developers Go API Reference
Definition: A temporary, cryptographically signed URL generated by the server that grants direct access to upload (PUT) or download (GET) a specific Object without requiring credentials.
Key attributes: `expiry_seconds` (Int), `url` (String).
Notes for Verity: Crucial pattern for client-side uploads.

---

### Object Lifecycle & Retention

Source: MinIO Object Lifecycle Reference
Definition: Rules managing automatic transition (tiering) or deletion of old objects based on age or version count.
Key attributes: `expiration_days` (Int), `noncurrent_version_expiration` (Int).
Notes for Verity: Helps manage photo storage costs automatically.
