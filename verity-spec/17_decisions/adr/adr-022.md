# ADR-022: Industry Packs are signed declarative artifacts

- Status: Accepted
- Date: 2026-09-16

An Industry Pack is canonical JSON data validated against the repository-owned
closed schema. It cannot contain SQL, shell, JavaScript, server callbacks, or
arbitrary expressions. Its canonical bytes are bound to a SHA-256 digest and an
Ed25519 signature from an explicitly trusted publisher key.

Validation occurs before preview and must be repeated before apply. It checks
schema, stable namespaced IDs, duplicates/collisions, the deliberately small
version-range grammar, platform compatibility, digest, publisher/key trust, and
signature. Contributions and migrations name operations supported by the
platform; naming one does not make customer-supplied code executable.

The validation contract is implemented first because no later lifecycle state
may safely accept an unsigned or ambiguous manifest. WP-10 remains partial until
tenant-scoped preview/approve/apply/reapply/upgrade/rollback, durable history,
and a sample-pack acceptance scenario are implemented and proven.
