# Architectural Decision Record

## ADR-006: Checklist Item Naming Enforcement

*   **Decision ID**: ADR-006
*   **Question**: Should the sub-steps of a Work Order be named `Task` or `ChecklistItem`?
*   **Context**: Duplicate terminology for sub-steps (Task) colliding with Project milestones.
*   **Affected Concepts**: `Work`, `Task`, `ChecklistItem`
*   **Evidence**: Odoo MRP workorder check lists; OpenProject tasks as parent milestone items.
*   **Evidence Location**: erpnext/projects/doctype/task/task.json
*   **Options**:
    *   *Option A*: Retain sub-step naming as `Task`.
    *   *Option B*: Force the term `ChecklistItem` for sub-steps and reserve `Task` for project-level milestones.
*   **Recommendation**: Option B.
*   **Status**: `ACCEPTED`
*   **Owner**: Product Owner
*   **Resolution**: Adopt Option B. To prevent semantic database collision, the sub-steps of a Work Order are canonically named `ChecklistItem` (GOV-TER-003). The term `Task` is reserved exclusively for independent, schedulable project-level milestone items.
*   **Supersedes**: None
*   **Superseded By**: None
*   **Confidence**: `HIGH`
